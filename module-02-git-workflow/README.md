# Module 02 — Git and Collaborative Workflow

## What is a branch?

Branch is a separate secluded workspace that developer can work on. Branch content will follow the branch source, and this workspace will not affect the original source workspace

## Why avoid working directly on main?

so that main branch is clean and not affected by unconfirmed work. this also provide a restoration point or comparison for any new work that was done
